图像模型对比台 —— 使用说明（v2）
================================
打开方式：直接双击 index.html（推荐 Chrome / Edge / Firefox 普通窗口），无需安装、无需联网。右上 ◐ 切换深色 / 浅色。

1. 新建对比组：右上「＋ 新建对比组」，填提示词（反向提示词、日期、标签、备注可选），保存后直接弹出选图窗口。
   - 组页面里的提示词默认折叠成两行（反向提示词、备注折叠为一行），点「展开全文」或直接点文字展开，点「收起」折叠。
2. 添加图片：一次多选，或把多张图片直接拖进页面（也支持 Ctrl+V 粘贴）。
   - 文件名自动预填为模型名（如 GPT-Image-1_001.png → GPT-Image-1），分辨率、画面比例自动读取。
   - 随后逐张弹出信息表单：平台、成本、耗时、默认参数（每行「键: 值」）、评分、优缺点、备注、是否最佳。
   - 成本默认单位是美元（$）。输入美元价格时，下方会实时显示人民币折算（例如 $0.04 ≈ ¥0.29）。
     汇率默认 $1 = ¥7.2，可在表单或工具栏修改（全局生效）。需要时也可切换为 ¥ / 积分 / 其他。
   - 评分为 10 分制：点 1–10 的数字方块即可，「清除」取消评分。
   - 「保存并编辑下一张」可连续填完一组。
3. 模型库：勾选「保存到模型库」后，下次同名模型（或文件名包含该模型名）自动填入平台 / 默认成本 / 默认参数。
4. 网格视图：并排看图，滑块调缩略图大小，可按成本 / 速度 / 评分 / 分辨率 / 模型名排序；绿色高亮为本组最优。
   鼠标移到图片上，左上角出现「对比」勾选框。
5. 表格视图：所有指标一张表，自动标出最便宜、最快、分辨率最高、评分最高；点表头可排序。美元价格同时显示 ≈ 人民币。
6. 点任意图片：左侧大图（滚轮缩放、拖拽平移、双击放大、1:1 原尺寸），右侧完整信息（提示词同样可折叠 / 展开）；
   ← → 切换同组其他模型，Esc 关闭。
7. 并排对比：在网格里勾选 2–4 张 →「对比所选」，同尺寸并排，默认同步缩放 / 平移。
8. 备份：「导出」生成一个包含全部图片的 JSON 文件；在其他电脑上「导入」即可（合并导入，同 ID 覆盖）。
   旧版本（5 星制）导出的文件也能导入：评分自动 ×2 换算为 10 分制，旧的「步数 / 种子」字段会被忽略。

注意：数据保存在当前浏览器的本地数据库（IndexedDB）里，换浏览器、清除网站数据或使用无痕模式都会看不到，请定期「导出」备份。
已用旧版本存过数据的，打开新版时会自动升级（评分 ×2、去掉步数 / 种子），只升级一次。
示例数据组的图片和数值都是虚构的，可直接删除。
src/ 目录是源码与自动化测试脚本，日常使用不需要。
